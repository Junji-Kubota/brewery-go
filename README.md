# Brewery GO

東京近郊のクラフトビール醸造所と、地元のクラフトビールが揃う酒屋を地図で探すアプリ。
「歩けば当たる」感覚で、近くの店を近い順に表示する。

公開ページ: https://junji-kubota.github.io/brewery-go/

## 機能
- 地図（OpenFreeMap／地理院地図）に店を表示。密集地はまとめて表示し、拡大すると店名が現れる
- 現在地から近い順のリスト、徒歩の目安時間、営業中の表示
- 店名・地名検索、絞り込み（種別、金銀銅ランク、飲んだ／まだ飲んでない、行きたい、営業中）
- 「飲んだ」「行きたい」の記録（ブラウザ内に保存）

## ファイル
- `index.html` … アプリ本体
- `data/places.js` … 店のデータ（試作用28件、2026-09-23調査）

## データの形式（data/places.js）
- `type`: `brewery`（醸造所）/ `shop`（酒屋）
- `h`: 営業時間。`"火-金15:00-23:00;土日12:00-22:00"` のように曜日と時間帯を書く。`null` は要確認
- `awards`: 直近の審査会の受賞数。`JGBA`=ジャパン・グレートビア・アワーズ、`IBC`=インターナショナル・ビアカップ、`WBC`=ワールドビアカップ
- `adj`: ランクの手動補正（知名度など）
- `founded`: 創業年、`src`: 情報元URL

## ランクの計算
受賞は金3・銀2・銅1点（WBCは2倍）、創業1999年以前+3点・2000〜2014年+1点、これに手動補正を足す。
12点以上=金、6点以上=銀、3点以上=銅。酒屋はランクなし。
